# CFRP AM Multi-sensor Dataset

This repository provides metadata and access information for the multi-sensor dataset used in the study "Development of a multi-sensor system for in situ process monitoring in robot-assisted continuous fiber composite additive manufacturing".

## Dataset

The full dataset is available on Zenodo:

https://doi.org/10.5281/zenodo.20174162

## Citation

Lu, L., Chen, Z., Cao, F., Cao, Y., Zhong, Y., Wang, M., Yuan, S., & Meng, X. (2026). Multi-sensor dataset for robot-assisted CFRP composite additive manufacturing [Data set]. Zenodo. https://doi.org/10.5281/zenodo.20174162

## Dataset contents

- Force signals
- Height signals
- Thermal images
- Visible images
